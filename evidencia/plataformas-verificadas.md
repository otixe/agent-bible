## Reglas de lectura para el manual

1. **Caracteres/bytes/tokens no son intercambiables.** 32KiB son32.768bytes; contexto de un modelo oRAG no da el máximo del editor de instrucciones.
2. **Instrucciones/documentos/cantidad deProjects son límites diferentes.** EnQuick,100.000chars se refiere a textoextraído de documentos subidos; la fuente no aclara aquí una fórmula per-file/total que debamos inventar.
3. **Aprobación no es sandbox.** Nunca/YOLO/bypass no son permiso de cliente, autorización para afectarservicios ni garantía de no red/escritura. Plan tampoco certifica ausencia de efectos frente aconfiguración/políticas/herramientas.
4. **Planes yrollouts envejecen.** Mantener fecha yURL. EnClaude, no mezclar la beta actual conProjectstradicionales; enChatGPT, no trasladar el límiteglobal aGPTs/Projects.
5. **GPTs cambiaron:** el artículo que antes se usaba como guía de instrucciones ahora describe disponibilidad; texto oficial indexado indica que crear/publicar nuevosGPTs no está disponible en cuentaspersonalesFree/Go/Plus/Pro. No convertir la cifra histórica8.000 en datoactual acreditado. Esto no confirma un límite alternativo.
6. **Import como sintaxis, no acción ejecutada aquí.** La notación @path se muestra en código para explicarla; en un CLAUDE.md real debe ir fuera de backticks/fences para expandirse. No invocamos CLI ni aprobamosimports/modos.
